Area of a Triangle, Sine Rule, Cosine Rule

Method fingerprint

  • Formulas are derived, not quoted — the only fully worked derivation in the 18 photos is the cosine rule.
  • Area: from A = ½bh with h = a sin C.
  • Sine rule: set up from a shared height as sin A = h/b, sin B = h/a — the rule itself is never written.
  • Cosine rule: drop a perpendicular, split base into x and c−x, substitute x = b cos A last.
  • Applied to find an obtuse angle, negative cosine accepted: cos B = −11/24.
