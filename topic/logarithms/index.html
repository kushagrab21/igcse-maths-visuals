This is the topic that decides the board

0580 says, in its own words, "Knowledge of logarithms is not required" (C2.5 and E2.5). These two sheets therefore cannot belong to a 0580 course. See ../../01_syllabus/board_evidence.md.

(c) Solving — the two starred requirements

Rejecting is required. A log's argument must be positive, so a root that makes any argument ≤0\le 0≤0 is discarded. The notes flag this as a step you must show.

Appropriate substitution. The same move serves two different-looking equations:

Method fingerprint

  • Exact values by conversion to index form: log₄32 = x → 4ˣ = 32.
  • The laws are called 'splitting' — the notes' own word.
  • Change of base is its own named heading, used for mixed-base equations and for simplification.
  • Solving has exactly two flagged requirements: 'Rejecting is required' and 'Appropriate substitution'.
  • Substitution applied to both a log equation and an exponential one.
  • log written with no base where the base is irrelevant.
